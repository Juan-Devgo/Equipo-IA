# Equipo-IA
Estos son archivos markdown de prompts de sistema para crear agentes de IA para que formen un equipo de desarrollo de software a través de una metodología basada en aspectos teóricos de la ingeniería de software. Por ejemplo, un agente desempeña el rol de product owner (PO), este ayuda a documentar de la mejor manera los requisitos y llevar un backlog priorizado (SCRUM). 

> [!IMPORTANT]
> Cabe aclarar que no se está usando la metodología SCRUM propiamente dicha, ni otra metodología ágil o tradicional, sólamente son agentes de IA que tienen un workflow definido y ayudan con aspectos específicos en un proyecto. Aunque sí se podría aplicar.

> [!NOTE]
> Los prompts de sistema fueron generados con Opus 4.6, especificándole qué roles se requerían y qué capacidades se requerían en cada uno. Claude Opus me ayudó creando estructura en los prompts y concretando todo con un lenguaje técnico y con herramientas que se usan en la industria.
